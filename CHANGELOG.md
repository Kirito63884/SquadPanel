# Changelog

## 0.5.1 — Discord V2-редизайн, анти-флуд, новые лимиты банов / Discord V2 redesign, anti-flood, ban limits

### Изменено / Changed
- **Все карточки бота в стиле Components V2** (Container + баннер MediaGallery + секция с аватаром-Thumbnail,
  заголовки, разделители, кнопки-ссылки): статус, баны/кики/варны (правило, срок, админ, апелляция, кнопки
  «Профиль в панели» и Steam), жалобы и вызовы админа (кнопки «Принять» / «Закрыть» → панель), дайджесты
  аудита, убийств и чата (компактные строки, дубликаты сворачиваются в «×N»). Все сообщения проверяются
  валидаторами discord.js (`@discordjs/builders`) в тестах; превью рендерится в настройках Discord.
- **Статус — одно постоянное сообщение на сервер в канале**, редактируется раз в 30–300 с (по умолчанию 45):
  карта, следующая карта, игроки/очередь, команды и тикеты, аптайм, «обновлено <t:R>». ID хранится, удалённое
  сообщение пересоздаётся. Отдельные посты «онлайн/офлайн» убраны — вместо них цвет (зелёный/жёлтый/красный).
  Баннер (https) — общий или для каждого сервера.
- **Анти-флуд**: аудит и действия админов собираются в один дайджест раз в ~60 с (15–600), дедупликация,
  шумные служебные события (`server.logsource`, `server.readonly`, `server.update`, логины, шаблоны, …)
  пропускаются (список настраивается), лимит сообщений в минуту на канал, для каждой категории — «сразу» или
  «в дайджест». После перезапуска воркера история аудита больше не переотправляется (раньше — главная
  причина флуда). Игровые бан/кик/варн ждут 25 с и не дублируются, если пришла карточка из панели.
- **Лимиты банов по рангам (по умолчанию)**: стажёр — до 3 дней (получает право `players.ban`), модератор — до
  14 дней, админ и выше — навсегда. Миграция `0007_discord_v2` обновляет встроенные роли существующих организаций
  (свои роли не трогает). Пресет срока «14d».
- Жалобы: статусы «принята»/«закрыта» из панели (`/reports?accept=…`), с записью в журнал.

### Обновление / Upgrade
- Миграция `0007` аддитивная (колонка `discord_integrations.options` + обновление лимитов встроенных ролей),
  применяется автоматически на PGlite и Postgres. После обновления проверьте «Настройки → Discord →
  Оформление и анти-флуд» и при желании задайте баннер.

## 0.5.0 — автоматизация, база игроков / automation, player database (phase 5b)

### Добавлено / Added
- **База игроков (как WARCON)** `/players`: все игроки, которых видели серверы организации, — поиск по
  нику, прошлым никам, EOS и Steam ID; фильтры «онлайн / все / забанены / наблюдение», фильтр по серверу,
  сортировка (последний/первый заход, ник, время в игре, сессии, K, D, K/D, TK), постраничный вывод.
  Постоянно пишутся: ID, история ников (первый/последний раз), первый/последний заход, серверы, время в игре,
  число сессий, время входа/выхода. Счётчики K/D/TK/ревайвов из лога, число варнов/банов/киков/заметок,
  аватар/ник/страна из публичного профиля Steam. Профиль показывает итоги, серверы, историю ников и сессии.
- **Правила автоматизации** для каждого сервера (`/servers/:id/automation`, право `automation.manage`):
  лимит тимкиллов (варн после N, кик после M, счёт переживает перезаход), AFK (эвристика, без админов/VIP,
  только при онлайне выше порога), объявления по таймеру с мин./макс. онлайном, сброс пустого сервера
  (`AdminChangeLayer` / `AdminSetNextLayer`), свои чат-команды с кулдауном, отсчёт перед рестартом.
  У каждого правила — переключатель, параметры и пробный прогон по событиям за 24 ч. Все действия идут через
  слой действий; на серверах «только чтение» только записываются. Изменения и действия — в журнале.
- **Голосование за смену карты**: кнопка админа и (опционально) `!skip` от игроков, голоса `!yes`/`!no`
  или `1`/`2`, длительность и порог в %, итог объявляется; при успехе — `AdminEndMatch` (или сначала
  `AdminSetNextLayer`). Аудит и уведомление в Discord.
- **Наблюдение (watchlist)**: игроки организации под наблюдением — уведомление в панели + счётчик в меню,
  категория Discord `watchlist`, страница списка и фильтр в базе игроков.
- **Сохранённые сообщения** организации (до 50, до 220 символов) — выбор в окнах объявления/варна.
- Discord: новые категории `kills`, `damage`, `squads`, `admin_camera`, `rcon_console`, `tickrate`,
  `watchlist` с пакетной отправкой (~10 с). Все сообщения переведены на Components V2.
- Discord-бот в сети через gateway (discord.js, только intent `Guilds`): статус и активность
  (по умолчанию «Не беспокоить» / Playing `SquadPanel.pro`) настраиваются в `/settings/discord`;
  переподключение, неверный токен не роняет воркер, корректный выход.

### Не сделано / Not possible
- Кик по пингу: Squad не отдаёт пинг ни в `ListPlayers`, ни в `ShowServerInfo`, ни в логе.
- Смена названия сервера на лету: в RCON нет команды, `ServerName` берётся из `Server.cfg` при запуске.
- Дистанция убийства: в логе Squad её нет.

### Миграция / Migration
- `0006_automation`: таблицы `player_servers`, `server_events`, `watchlist`, `saved_messages`; колонки
  `players.kills/deaths/teamkills/revives`, `servers.automation`, `steam_profiles.country`,
  `discord_integrations.presence_status/presence_activity`. Данные не удаляются. Заполнение из старых данных:
  игроки из банов и варнов, история ников, счётчики K/D/TK из `combat_events`, серверы и время в игре из
  `player_sessions`. Старшему и тех. админу добавляется `automation.manage`.

## 0.4.0 — модерация / moderation (phase 5a)

### Добавлено / Added
- Роли «Тех. админ» (45) и «Только чат» (5); новое право `players.view` (игроки, отряды, профили —
  раньше входило в `view`) и `bans.manage` (настройки банлиста и шаблоны). Роль «только чат» видит
  статус сервера и чат, игроки и отряды скрыты и в API воркера.
- Лимит бана у каждой роли (`max_ban_minutes`): Старший — любой, Админ — до 30d, Модератор — до 1d,
  остальные — без банов. Проверяется на сервере (`performAction`, `createBan`, `updateBan`); в окне бана
  показываются только разрешённые сроки. Владелец меняет лимиты на вкладке «Лестница».
- Банлист организации `/bans`: поиск, фильтры, кто выдал, срок, изменение срока/причины, разбан
  (по лестнице), бан на все серверы или один, сообщение при бане с `{reason} {expires} {duration} {appeal}`,
  ссылка на обжалование, выгрузка `Bans.cfg` (только скачивание).
- Бан по EOS/Steam ID (офлайн): воркер кикает игрока при заходе (join / снимок / heartbeat), пока бан
  активен; повторный кик не чаще раза в 20 с; на серверах «только чтение» — только запись в журнал.
- Бан из панели теперь хранится в банлисте и выполняется кик с сообщением (опция — дублировать в игровой
  `Bans.cfg` через `AdminBan`).
- Варны со сроком (по умолчанию 30d, настраивается): активные/истекшие в профиле игрока и метки у ников.
- Шаблоны причин (текст + срок) для бана, варна и кика, выбор в окнах действий; 8 шаблонов по умолчанию.
- Отряды: сброс названия (`AdminRenameSquad <TeamId> <SquadIndex>`), меню по правому клику на заголовке
  отряда, более явные блоки отрядов (номер, название, лидер, размер/9, замок, киты) и блок «Без отряда».

### Не сделано / Not possible
- Закрыть/открыть отряд из панели: в Squad RCON нет админ-команды для этого (только кнопка лидера в игре).

### Миграция / Migration
- `0005a_moderation`: новые таблицы `bans`, `player_warns`, `reason_templates`, колонки
  `org_roles.max_ban_minutes`, `organizations.settings`; данные не удаляются. Всем ролям добавляется
  `players.view`, Старшему — `bans.manage`; новые роли и шаблоны создаются для существующих организаций.
